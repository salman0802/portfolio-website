# Jubal Studio V11

- Restored normal scrolling for the full Performance workspace. The Performance Console and dock panels are no longer fixed-priority/sticky regions.
- The optional main Performance keyboard remains the only sticky content surface when the user enables the pin preference.
- Added Practice Scale controls (root + Western/Hindustani/Carnatic scale/raga type).
- Added Practice Accompaniment controls (on/off, voice, zone, octave shift and inversion).
- Live and Practice harmony controls are synchronized and persist through the existing app settings.
- Practice scale changes immediately update scale highlighting on both keyboards.
- Manual playing on the Practice piano can now use the shared accompaniment engine; imported MIDI playback remains unchanged and is not reharmonized.
